# Как задеплоить актуальный код на Railway

Если бот не отвечает или в логах 409 / BUTTON_TYPE_INVALID — почти всегда на Railway крутится **старая сборка**. Сделайте по шагам.

## 1. Убедитесь, что деплой идёт из этого репозитория

- Откройте проект на [railway.app](https://railway.app) → ваш сервис.
- **Settings** → **Source** (или **Connect Repo**): должен быть подключён **тот же GitHub-репозиторий**, в котором вы правите код (папка `c:\Work\coffee bot`).
- Запомните **ветку** (часто `main` или `master`). Деплой должен быть с неё.

## 2. Закоммитьте и запушьте все изменения

В папке проекта (например в терминале Cursor):

```bash
cd "c:\Work\coffee bot"
git status
```

Должны быть изменённые файлы (например `src/index.js`, `src/bot.js`, `src/server.js`). Если есть несохранённые правки в редакторе — сохраните их.

```bash
git add -A
git commit -m "fix: webhook + ответ ссылкой без кнопки"
git push origin main
```

(Если ветка у вас не `main`, подставьте свою, например `master`.)

## 3. Перезапустите деплой на Railway

- **Deployments** → последний деплой → кнопка **Redeploy** (или **Deploy**).
- Дождитесь окончания сборки (Build → Deploy).
- Откройте **View Logs** у нового деплоя.

## 4. Проверьте, что запустилась новая версия

В логах при старте **обязательно** должны быть строки:

```
☕ COFFEE_BOT v2 — Сервер на порту 8080
   Mini App URL: https://coffee-bot-production.up.railway.app
   Бот в режиме WEBHOOK (без 409): https://coffee-bot-production.up.railway.app/telegram-webhook
```

- Если видите **«COFFEE_BOT v2»** и **«режиме WEBHOOK»** — на сервере новая версия.
- Если этих строк **нет** (только «Сервер запущен» и «Mini App URL») — на Railway всё ещё старая сборка. Тогда:
  - Проверьте, что `git push` ушёл в тот репозиторий и ветку, откуда деплоит Railway.
  - В Railway: **Settings** → **Build** → попробуйте **Clear build cache** и снова **Redeploy**.

## 5. Проверка в Telegram

В группе отправьте **/start**. Бот должен ответить **одним сообщением со ссылкой** (синий текст «Сбор на кофе»), **без кнопки** под сообщением. Нажатие на ссылку открывает Mini App.

Если бот по-прежнему не отвечает — пришлите скрин логов Railway (первые 15–20 строк после «Starting Container»).
