# ☕ Coffee Bot — Mini App для сбора друзей на кофе в Telegram

Бот с **Mini App** (веб-приложением внутри Telegram): любой в группе открывает приложение, запускает сбор на кофе, выбирает время; остальные голосуют «Участвую» / «Не смогу»; инициатор подтверждает — бот напоминает в выбранное время.

---

## Как это работает

1. В группе кто-то пишет **/start** — бот присылает кнопку **«☕ Сбор на кофе»**.
2. Нажатие открывает **Mini App**: выбор времени (15 / 30 / 45 мин или 1 час) и создание сбора.
3. Остальные открывают то же приложение (кнопка в том же сообщении) и нажимают **«✅ Участвую»** или **«❌ Не смогу»**.
4. Когда все проголосовали, **инициатор** в приложении нажимает **«🔒 Подтвердить сбор»**.
5. Бот пишет в чат о подтверждении и в выбранное время отправляет: **«☕ Время! Идём за кофе.»**

## Полная инструкция: как подключить в Telegram

### Шаг 1. Создать бота в BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду **`/newbot`**.
3. Введите имя бота (например: `Coffee Collection`) и username (например: `my_coffee_collection_bot`). Username должен заканчиваться на `bot`.
4. BotFather пришлёт **токен** вида `123456789:ABCdefGHI...`. Скопируйте его — он понадобится для `.env`.

### Шаг 2. Установить проект и настроить .env

На компьютере в папке проекта:

```bash
cd "c:\Work\coffee bot"
npm install
```

Создайте файл **`.env`** (скопируйте из `.env.example` и подставьте свои значения):

```env
BOT_TOKEN=сюда_вставить_токен_от_BotFather
PORT=3000
BASE_URL=https://ваш-публичный-адрес.ваш-хостинг.app
```

- **BOT_TOKEN** — токен из шага 1.  
- **PORT** — порт сервера (можно оставить 3000).  
- **BASE_URL** — **обязательно** публичный **HTTPS**-адрес, по которому будет открываться Mini App (см. шаг 3).

### Шаг 3. Получить HTTPS-адрес для Mini App

Telegram открывает Mini App только по **HTTPS**. Варианты:

#### Вариант A: Локальная разработка (ngrok)

1. Установите [ngrok](https://ngrok.com/download).
2. В одном терминале запустите бота: `npm start`.
3. В другом: `ngrok http 3000`.
4. Скопируйте выданный HTTPS-URL (например `https://abc123.ngrok.io`) и вставьте в **BASE_URL** в `.env`. Перезапустите `npm start`.

#### Вариант B: Хостинг (Railway / Render / другой)

1. Залейте проект в Git (GitHub/GitLab).
2. Создайте приложение на [Railway](https://railway.app) или [Render](https://render.com):
   - Подключите репозиторий.
   - Укажите команду запуска: `npm start` (или `node src/index.js`).
   - Укажите порт из переменной **PORT** (часто хостинг сам задаёт PORT).
3. В настройках сервиса добавьте переменные окружения: **BOT_TOKEN**, **BASE_URL** (и при необходимости **PORT**).  
   **BASE_URL** — тот адрес, который выдаст хостинг (например `https://your-app.up.railway.app`). Без слеша в конце.
4. После деплоя скопируйте URL приложения и убедитесь, что он прописан в **BASE_URL** (в .env локально или в переменных хостинга).

### Шаг 4. Запустить бота

Локально:

```bash
npm start
```

В логах должно быть что-то вроде:  
`Сервер запущен на порту 3000` и `Mini App URL: https://...`.

### Шаг 5. Добавить бота в группу и открыть Mini App

1. Создайте группу в Telegram или откройте существующую.
2. Добавьте бота в группу (через «Добавить участников» → поиск по username бота).
3. В группе отправьте команду **`/start`**.
4. Под сообщением бота появится кнопка **«☕ Сбор на кофе»** — она открывает Mini App.
5. Нажмите кнопку: должно открыться приложение (выбор времени, голосование, подтверждение).

Если кнопка не открывает приложение или пишет ошибку — проверьте, что **BASE_URL** в `.env` (или на хостинге) совпадает с реальным HTTPS-адресом и что сервер запущен и доступен из интернета.

### Шаг 6. (По желанию) Кнопка в профиле бота (Menu Button)

Чтобы Mini App можно было открывать из профиля бота:

1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте **`/mybots`** → выберите вашего бота.
3. **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Укажите:
   - **URL:** ваш **BASE_URL** (тот же, что в .env), например `https://your-app.up.railway.app`.
   - **Текст кнопки:** например `Открыть сбор на кофе`.

В группе по-прежнему удобнее использовать кнопку под сообщением после **/start** (в URL уже подставляется chatId). Menu Button полезен для быстрого доступа из лички или профиля.

## Структура проекта

| Что | Описание |
|-----|----------|
| `src/index.js` | Запуск сервера и бота, чтение `.env` |
| `src/bot.js` | Логика бота и кнопка «Сбор на кофе» (открывает Mini App) |
| `src/server.js` | Express: раздача Mini App и API для сборов/голосов/подтверждения |
| `src/state.js` | Хранение активных сборов и таймеров (в памяти) |
| `public/index.html` | Страница Mini App |
| `public/app.js` | Логика Mini App (Telegram Web App API, вызовы API) |

---

## Требования

- Node.js 18+
- Групповой чат в Telegram (группа или супергруппа)
- Публичный **HTTPS**-адрес для Mini App (ngrok или хостинг)

Данные о сборах хранятся в памяти; после перезапуска приложения активные таймеры сбрасываются.
